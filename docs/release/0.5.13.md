# AuthTwin 0.5.13

Date: 2026-08-10

## Guided Web Security Console

AuthTwin keeps its authorization-native dashboard and uses the SRIC Core 0.5.13 guided Security Console for complete operations.

- Dashboard navigation is `Dashboard / Security Console / API`.
- `All Features` and `Advanced Console` are removed from user-facing navigation.
- Users configure AuthTwin capabilities through operation cards, checkboxes, selectors, numeric/path controls and structured repeated-value controls rather than command or argv entry.
- `/console` remains only as a compatibility alias to `/workbench`.
- Authorization Matrix, actors/resources, coverage, findings, counterfactual plans, evidence drawer and live job status remain domain-native.
- Unobserved authorization cells remain `UNKNOWN`; the UI does not promote gaps to vulnerabilities.

## Runtime and supply chain

- Product version: 0.5.13.
- SRIC Core floor: `>=0.5.13,<0.6`.
- First-party runtime pin: GitHub-verified SRIC commit `bd90fe668e4a2a23c00a39f7d63df1c092b63c12`.

- Linux and Windows installers require SRIC 0.5.13 and retain atomic product/SRIC installation, `pip check`, shared Web import probes and quiet doctor/help smokes.
